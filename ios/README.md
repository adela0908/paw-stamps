# Paw Stamps — native iOS app

SwiftUI rebuild of the Paw Stamps web app, targeting **iOS 15+** (runs on 2015-era iPads through current devices).

## Layout

- `project.yml` — [XcodeGen](https://github.com/yonaskolb/XcodeGen) spec; regenerate the project with `xcodegen generate`
- `PawStamps/` — all Swift sources, asset catalog, and sounds
- `scripts/make_assets.py` — regenerates the app icon and WAV sound effects from code (no binary asset dependencies)

## Build & run

```bash
cd ios
xcodegen generate          # only needed after adding/removing files
open PawStamps.xcodeproj   # then ⌘R in Xcode, or:
xcodebuild -project PawStamps.xcodeproj -scheme PawStamps \
  -destination 'platform=iOS Simulator,name=iPad (10th generation)' build
```

Requires full Xcode (not just Command Line Tools).

## App structure

| File | Responsibility |
|---|---|
| `Models.swift` | `AppState` (Codable), `Store` (persistence via UserDefaults + all mutations) |
| `Theme.swift` | Palette, chunky sticker-card modifier, pressable button style |
| `CatArt.swift` | Mascot, paw-print stamp, big slam stamp — all vector `Shape`s |
| `PawStampsApp.swift` | App entry, tab shell, header, FAB, overlay orchestration |
| `WalletView.swift` | Stamp cards of 10, full-card chips, fresh-stamp slam-in |
| `RewardsView.swift` | Reward rows with progress bars and gated redeem |
| `HistoryView.swift` | Day-grouped ledger |
| `Overlays.swift` | PIN gate, give-stamp form, redeem confirm, celebration, confetti, onboarding |
| `SettingsView.swift` | Parent settings: name, PIN, sound, balance fix, rewards editor, reset |
| `SoundPlayer.swift` | Bundled WAV effects (generated by `make_assets.py`) |

All data lives on-device (UserDefaults JSON blob under `pawstamps.state.v1`). No network, no analytics, no accounts — by design, for Kids Category compliance.
